# CXR Titration Laboratory — Virtual Reality Chemistry Lab

An immersive virtual reality chemistry laboratory developed using Unity, focused on interactive laboratory environments and VR-based learning experiences.

## Overview

The CXR Titration Laboratory project explores the use of virtual reality to create an interactive chemistry laboratory environment. It aims to provide users with an immersive space to explore laboratory equipment and engage with a virtual laboratory setup.

## Objectives

- Create an immersive virtual chemistry laboratory environment.
- Integrate 3D laboratory assets into a Unity scene.
- Explore interactive laboratory experiences using XR technologies.
- Support virtual laboratory exploration and experiential learning.

## Technologies

- **Game Engine:** Unity
- **Programming:** C#
- **3D Assets:** Project-specific 3D models and materials
- **XR Framework:** Add the XR framework actually used in this project


## Features

- Virtual chemistry laboratory environment
- 3D laboratory equipment and scene assets
- Immersive laboratory exploration
- VR interactions, where implemented

## Project Context

This project is associated with work undertaken at the Centre for Extended Reality (CXR), GITAM University, under the guidance of Dr.M.Kranthi kiran.
